# 🚀 AI Resume Builder (MERN Stack)

Is an AI-powered web application that helps users create professional, ATS-friendly resumes in seconds.
Built with the MERN stack and integrated with Gemini AI for real-time smart content generation.

## 🔗 Live Links
- **Live Demo:** [https://reume-mate-frontend.vercel.app/]
- **Backend Repository:** [https://github.com/awanayaan97-maker/ResumeMate]

## 🔥 Key Features
- **Real-Time Preview:** Users can see changes instantly as they type (`oninput` integration).
- **AI-Powered Content:** Automatically generates professional summaries and job descriptions using Google Gemini API.
- **Dynamic Mobile PDF Download:** High-resolution, crisp PDF downloads on both Mobile and Desktop devices using optimized `html2pdf.js` configurations.
- **Clickable Links Validation:** In-app links (GitHub, LinkedIn) are fully interactive and auto-validated with proper protocols.

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Libraries:** html2pdf.js, html2canvas, jsPDF
- **Backend Service:** Connected via REST APIs to a decoupled Node.js server.
